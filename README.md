# Jarisisant

Настольный ассистент для Windows: пишете, что сделать, и он делает. Модель выбирается
вручную и сама никогда не переключается.

## Что умеет

- открыть сайт, поиск Google или видео на YouTube;
- запустить программу из меню «Пуск»;
- создать папку, создать и прочитать текстовый файл;
- удалить файл или папку в корзину (всегда с подтверждением);
- просто разговаривать, помня последние сообщения.

Файлы доступны только на рабочем столе, в «Документах» и «Загрузках» (другие папки
добавляются в `ALLOWED_DIRS`).

## Модели

| Профиль | Что это | Что нужно |
|---|---|---|
| `ollama` | локальная модель, без интернета | [Ollama](https://ollama.com/download) и `ollama pull qwen3:8b` |
| `gemini` | Gemini, бесплатный лимит | ключ из [AI Studio](https://aistudio.google.com/apikey) |
| `deepseek` | DeepSeek, очень дешёвая | ключ с [platform.deepseek.com](https://platform.deepseek.com) |
| `claude` | Claude, платная и самая умная | ключ с [platform.claude.com](https://platform.claude.com) |

Модель переключается в выпадающем списке окна или в меню иконки в трее.

## Установка

```bash
python -m venv .venv
```

```bash
.venv\Scripts\python.exe -m pip install -r requirements.txt
```

```bash
copy .env.example .env
```

Откройте `.env` и впишите ключи тех моделей, которыми будете пользоваться.

## Запуск

Двойной щелчок по `run.bat`, либо из терминала:

```bash
.venv\Scripts\python.exe -m jarisisant
```

Закрытие окна сворачивает ассистента в трей. Выход: правый щелчок по иконке, «Выход».
